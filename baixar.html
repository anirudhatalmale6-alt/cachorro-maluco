2. Siga os passos

Passo 1 — Criar a conta (só a primeira vez)

  1. Entre no site itch.io
  2. Clique em Register, no canto de cima à direita
  3. Preencha Username (nome sem espaço), Email e Password
  4. Marque a caixinha "I am interested in distributing content on itch.io"
  5. Clique em Create account
  6. Abra o seu email e clique no link de confirmação que eles enviam

Passo 2 — Criar o jogo

  1. Entre em itch.io/dashboard
  2. Clique no botão Create new project

Passo 3 — Preencher a ficha

  • Title: Cachorro Maluco
  • Short description: use o Texto 1, mais abaixo
  • Classification: Games
  • Kind of project: HTML
  • Release status: Released
  • Pricing: No payments
O "Kind of project" tem que ser HTML Se marcar outra coisa, o jogo não abre no navegador e ninguém consegue jogar.

Passo 4 — Enviar o jogo

  1. Desça até a parte Uploads
  2. Clique em Upload files
  3. Escolha o arquivo cachorro-maluco-jogo.zip na pasta Downloads
  4. Espere a barrinha encher até o fim
  5. Vai aparecer uma caixinha escrita "This file will be played in the browser". Marque ela.
Esta é a caixinha mais importante de todas Sem marcar "This file will be played in the browser", o site trata o jogo como um arquivo para baixar e ninguém consegue jogar direto na página.

Passo 5 — Ajustar o tamanho da tela

Logo abaixo aparece Embed options:

  • Viewport width: 400
  • Viewport height: 720
  • Marque Mobile friendly
  • Marque Fullscreen button

Passo 6 — As imagens

  • Cover image: capa.png
  • Screenshots: tela1-inicio.png, tela2-jogando.png, tela3-fim.png e tela4-computador.png

Passo 7 — Descrição e etiquetas

  • Details (descrição longa): use o Texto 2, mais abaixo
  • Genre: Action
  • Tags: use o Texto 3, digitando um por um

Passo 8 — Publicar

  1. Lá embaixo, clique em Save & view page
  2. Veja como ficou e teste jogar
  3. Estando tudo certo, clique em Edit game de novo
  4. Mude Visibility & access para Public
  5. Salve

Pronto. A partir daqui qualquer pessoa do mundo pode jogar.
